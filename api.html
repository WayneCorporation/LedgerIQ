ledgerIQ API

Use an API key created in the Enterprise control centre as a bearer token. Keys are shown once and can be revoked at any time.

Authentication

Authorization: Bearer lq_your_key

Read-only keys can call GET endpoints. Keys with the write scope can create and update finance records but cannot access account security, billing, API-key or webhook-secret endpoints.

POST /api/clients
PUT  /api/clients/:id
POST /api/invoices
PUT  /api/invoices/:id

Outbound webhooks

ledgerIQ signs the exact JSON body using HMAC-SHA256. Compare the hexadecimal result to X-LedgerIQ-Signature. Use X-LedgerIQ-Delivery as the unique delivery identifier and make consumers idempotent.

Errors and limits

Responses are JSON. Errors use {"error":"message"}. Uploaded files are limited to 5 MB. Bank imports accept up to 1,000 transactions per request. Treat HTTP 429 as retryable with exponential backoff.
